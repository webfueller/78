Paste the thread you're dreading.

You get the week as it probably goes: whether a nudge gets answered, how likely that is, and what leaving it alone costs. Then a picture of it you can save.

  • 01A branch map. One line per plan, one endpoint per way the week can land, thickness by probability.
  • 02The odds, and where they came from. One thread is thin evidence and the page says so in as many words rather than rounding it into confidence.
  • 03A card to post. Plan names, counts and probabilities — no names, no subject lines, no message text.

What this costs you

  • ✓No account. There is no sign-up on this page and no cookie set by it.
  • ✓Nothing written down. Your thread is parsed into an in-memory database that is closed and freed before the response is sent. There is no file for it to land in.
  • ✓Nowhere to go. The server binds to loopback. It is running on the machine in front of you, and it has no outbound connection to make.
  • ✓Your address is a comparison. It is used once, to work out which messages in the paste are yours, and discarded with everything else.

Take the claim as far as you like: it is preflight/paste.py, about two hundred lines, and the test suite asserts the trunk's hash is unchanged after a paste.

Gmail-style and Apple-Mail-style dates both parse. Two messages is enough; more is better.
